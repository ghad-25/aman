# أمان | AMAN — الدليل التقني (v1.2)

**الرابط الحي:** https://aman-medathon.netlify.app · **نظرة عامة على المشروع:** [README.md](README.md)

يسجّل الطبيب مريضه ويحدد حالته، فتُبنى قائمة الأدوية التي يجب تجنّبها تلقائيًا. ثم يُكتب رابط المريض على إسوارة NFC. أي معالج يلمس الإسوارة بجواله تفتح له بطاقة الطوارئ، ويستطيع فحص أي دواء قبل إعطائه والتواصل مع الطبيب المعالج من نفس الصفحة. كل البيانات محفوظة على الخادم، ويشترك فيها كل الأجهزة.

## التشغيل المحلي
يتطلب Node.js 18 أو أحدث.
```
npm install
npm run dev
```
ثم افتح http://localhost:8888. تُحفظ البيانات محليًا في مجلد `.data/`.

| | |
|---|---|
| حساب الطبيب التجريبي | `doctor@aman.demo` / `123456`، أو زر «دخول سريع بحساب التجربة» |
| سارة (وهن عضلي) | البطاقة `/m/demo-sara`، ورمز الملف الكامل `6305` |
| يوسف (نقص G6PD) | البطاقة `/m/demo-yousef`، ورمز الملف الكامل `2580` |
| إعادة ضبط بيانات التجربة | زر «إعادة ضبط» في الصفحة الرئيسية للوحة الطبيب |

## النشر على Netlify
1. اربط المستودع بـ Netlify: **Add new site ← Import from Git**. الإعدادات تُقرأ تلقائيًا من `netlify.toml`.
2. بعد النشر افتح `https://<الموقع>/api/health`، ويجب أن يظهر `"store":"blobs"`.

**ملاحظات:**
- **Netlify Drop (سحب المجلد إلى المتصفح) لا يصلح:** يرفع الصفحات فقط بدون الخادم.
- **التخزين:** Netlify Blobs، مدمج في Netlify ولا يحتاج قاعدة بيانات ولا مفاتيح. يُطلب عميل تخزين جديد مع كل عملية، لأن Netlify يصدر تصريح وصول قصير العمر لكل طلب.
- **المفاتيح:** مفتاح توقيع الجلسات ومفاتيح الإشعارات (VAPID) تتولد تلقائيًا عند أول استخدام وتُحفظ في التخزين. ويمكن تحديدها يدويًا بالمتغيرات `AMAN_SESSION_SECRET` و`AMAN_VAPID_PUBLIC` و`AMAN_VAPID_PRIVATE`.

**النشر بدون GitHub:**
```
npm i -g netlify-cli
netlify login
netlify deploy --prod
```

## كتابة الإسوارة
1. من لوحة الطبيب: «وسائل الوصول» ← «نسخ الرابط» (الرابط القصير `/m/...`).
2. في تطبيق NFC Tools (أندرويد أو آيفون): Write ← Add a record ← URL، ثم الصق الرابط والمس الشريحة. الشرائح المناسبة: NTAG213 أو 215 أو 216.
3. جرّب الرابط، ثم **اقفل الشريحة (Lock)** حتى لا تُعدَّل. القفل نهائي.

عند ضياع الإسوارة: «إيقاف» ثم «رابط جديد». يتوقف الرابط القديم فورًا.

## مبدأ السلامة: دواء خطأ أسوأ من لا جواب
- لا يُفحص تلقائيًا إلا الاسم المطابق تمامًا. الأسماء القريبة تُعرض كاقتراح يحتاج تأكيدًا.
- أي كلمة غير معروفة بجانب اسم معروف (مثل «Extra» أو «Plus») تعني: تحقق من باقي المكونات.
- إذا اختلف التحذير حسب طريقة الإعطاء (مثل المغنيسيوم بالفم أو بالوريد)، يُسأل المعالج عن الطريقة.
- الباركود غير المسجّل لا يُخمَّن، ويُطلب كتابة اسم الدواء.
- التحذير الذي يزيله الطبيب لمريض معيّن يبقى ظاهرًا بمستوى «بحذر» مع عبارة «أزاله الطبيب المعالج».

## تنبيه الطبيب المعالج
- **تنبيه تلقائي:** عند كل نتيجة «تجنّب» لمريض الطبيب، من الإسوارة أو البطاقة، بالاسم أو بالباركود. يُرسل **مرة واحدة لكل دواء لكل مريض في 24 ساعة** لتجنّب كثرة التنبيهات، ولا يُرسل لنتائج «بحذر» و«معلومة». ويمكن إيقافه لكل مريض من ملفه.
- **طلب تواصل:** عندما يضغط المعالج «اتصل بالطبيب المعالج». يرد الطبيب من «التنبيهات»، ويظهر الرد عند المعالج فورًا.

**إشعارات الجوال:**
- **أندرويد:** تُفعَّل من لوحة الطبيب في Chrome مباشرة.
- **آيفون (iOS 16.4 أو أحدث):** تُضاف لوحة الطبيب إلى الشاشة الرئيسية من Safari (زر المشاركة ← «إضافة إلى الشاشة الرئيسية»)، ثم تُفعَّل الإشعارات من داخلها.

## مسح باركود الدواء
- **الفكرة:** باركود علبة الدواء في السعودية يحمل رقم المنتج العالمي (GTIN)، ومعه في مربع DataMatrix تاريخ الانتهاء والتشغيلة والرقم التسلسلي، ولا يحمل اسم الدواء. تطبيق «طمني» يقرأ الرقم ثم يبحث عنه في سجل منتجات الهيئة. وأمان يفعل الشيء نفسه مع **مكتبة باركود أمان**، ثم يفحص الدواء للمريض.
- **القراءة:** في المتصفح بدون تطبيق، بالكاميرا أو من صورة. تُستخدم BarcodeDetector المدمجة في المتصفح عند توفرها، ومكتبة ZXing بديلًا. والكاميرا تتطلب رابطًا آمنًا (https).
- **ربط العلب:** يربط الطبيب العلبة مرة واحدة من «باركود الأدوية»، بعد التحقق من خانة التحقق في الرقم، ولا يُقبل إلا اسم دواء معروف بالضبط.
- **باركودات للتجربة:** في `/demo-barcodes`. تبدأ بالبادئة 20 المخصصة في GS1 للاستخدام الداخلي، فلا تطابق أي منتج حقيقي.

## خارج نطاق هذه النسخة
- الربط التلقائي للباركود بسجل الهيئة. قائمة الأدوية العامة المنشورة لا تتضمن الباركود، فالربط حاليًا يدوي.
- قراءة اسم الدواء المكتوب على العلبة (OCR).
- الإضافة الرسمية إلى Apple Wallet وGoogle Wallet، وتتطلب شهادات مطوّر. البديل الحالي حفظ البطاقة صورة.
- إرسال التنبيه برسالة نصية (SMS).
- التحقق من هوية الطبيب عند التسجيل، واستعادة كلمة المرور.
- شريحة NTAG 424 DNA التي تولّد رابطًا جديدًا مع كل لمسة.
- الاستضافة داخل المملكة.
- **المراجعة السريرية:** قائمة الأدوية مأخوذة من المسودة v2 (`data/aman_drug_rules_draft_v2.xlsx`)، وتنتظر توقيع المراجعة السريرية في ورقة `review_signoff`.

## تحديث قواعد الأدوية
1. عدّل `data/aman_drug_rules_draft_v2.xlsx`.
2. شغّل:
   ```
   pip install openpyxl
   npm run rules
   npm test
   ```
3. يعيد الأمر `npm run rules` توليد `lib/rules-data.mjs`، وهو المصدر الوحيد الذي تُبنى منه البطاقة والفحص معًا.

## الاختبارات
يشغّل `npm test` ثمانية وعشرين اختبارًا آليًا، منها:
- كل قاعدة «تجنّب» تُكتشف باسمها العربي والإنجليزي.
- كل الأسماء التجارية الـ471 توصل لدوائها الصحيح.
- الإملاء القريب لا يُفحص بدون تأكيد.
- الإسوارة الموقوفة لا تفتح البطاقة ولا الفحص.
- قفل رمز الملف الكامل.
- عزل مرضى كل طبيب عن غيره.
- حلقة الطبيب المعالج كاملة.
- قراءة الباركود الخطي ومربع DataMatrix مع تاريخ الانتهاء.
- التنبيه التلقائي: مرة لكل دواء، وإيقافه لكل مريض، ووصوله للجوال، وحذف الأجهزة المنتهية.

## هيكل المشروع
```
public/                      الصفحات + assets (aman.js وqr.js وscanner.js وZXing)
public/sw.js                 يعرض الإشعار على الجوال ويفتح التنبيهات
public/manifest.webmanifest  اسم التطبيق وأيقونته عند الإضافة للشاشة الرئيسية
netlify/functions/api.mjs    نقطة دخول الخادم على Netlify (/api/*)
lib/api.mjs                  مسارات الخادم
lib/engine.mjs               محرك فحص الدواء وقوائم البطاقة
lib/rules-data.mjs           القواعد (مولّدة من ملف الإكسل)
lib/gs1.mjs                  قراءة باركود GS1 (رقم المنتج، الانتهاء، التشغيلة)
lib/push.mjs                 إشعارات الجوال (Web Push)
lib/store.mjs                التخزين: Netlify Blobs على الموقع، وملفات محلية للتطوير
lib/security.mjs             كلمات المرور والتوقيع والجلسات
lib/demo.mjs                 بيانات المرضى والباركودات التجريبية (شخصيات وهمية)
scripts/build_rules.py       توليد القواعد من ملف الإكسل
dev-server.mjs               خادم التشغيل المحلي
test/                        الاختبارات
```

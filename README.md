# أمان | AMAN

### التحذير يرافق المريض أينما ذهب

بعض الأمراض النادرة تجعل أدوية شائعة خطيرة على صاحبها، مثل الوهن العضلي الوبيل ونقص إنزيم G6PD. وأخطر لحظة يمر بها المريض هي حين يُعالَج عند شخص لا يعرف حالته: في الطوارئ، أو في مستشفى آخر، أو في صيدلية. المعلومة موجودة عند طبيبه، لكنها لا تصل وقت كتابة الدواء أو صرفه.

**أمان** يحمل قائمة الأدوية التي يجب تجنّبها، المعتمدة من الطبيب المعالج، على إسوارة NFC أو بطاقة رقمية في جوال المريض. أي شخص يلمس الإسوارة بجواله يرى بطاقة الطوارئ فورًا، بدون تطبيق ولا تسجيل دخول، ويفحص أي دواء قبل إعطائه.

**الرابط الحي:** https://aman-medathon.netlify.app

---

## كيف يعمل

1. **الطبيب** يسجّل مريضه ويختار حالته، فتُبنى قائمة التجنّب تلقائيًا من مكتبة أمان، ثم يعدّلها لهذا المريض.
2. **المنصة** تصدر للمريض رابط إسوارة وبطاقة رقمية، ورمزًا من 4 أرقام لفتح الملف الكامل.
3. **المعالج** يلمس الإسوارة أو يمسح رمزها، فيرى الحالة والأدوية الممنوعة وأرقام التواصل.
4. **فحص الدواء:** يكتب المعالج اسم الدواء أو يمسح باركود العلبة، فتظهر النتيجة: تجنّب، أو بحذر، أو معلومة للطاقم، أو لا يوجد تنبيه.
5. **الطبيب المعالج** يصله تنبيه تلقائي عند كل نتيجة «تجنّب»، ويستطيع المعالج طلب التواصل معه وانتظار ردّه من نفس الصفحة.

## المزايا

| | |
|---|---|
| **بطاقة طوارئ بلمسة** | تفتح من أي جوال، بدون تطبيق ولا تسجيل دخول |
| **فحص الدواء** | 100 قاعدة و471 اسمًا تجاريًا وعربيًا، مع طريقة الإعطاء والتداخل مع أدوية المريض الحالية |
| **مسح باركود العلبة** | يقرأ الباركود الخطي ومربع DataMatrix ويتحقق من تاريخ الانتهاء، بنفس طريقة تطبيق «طمني» |
| **عرضان للنتيجة** | المريض يرى التنبيه وسببه بكلام بسيط، والطاقم الصحي يرى الإجراء والمصدر |
| **حلقة الطبيب المعالج** | تنبيه تلقائي عند «تجنّب»، وطلب تواصل يصل للوحة الطبيب وإشعار على جواله |
| **الخصوصية** | الإسوارة تحمل رابطًا فقط، والملف الكامل يحتاج رمزًا، وكل فتح يُسجَّل، والإسوارة الضائعة تُوقف بضغطة |
| **«دواء خطأ أسوأ من لا جواب»** | لا نفحص اسمًا غير مؤكد، ولا نخمّن دواءً من باركود غير مسجّل |

## التقنية

- **الواجهة:** HTML وJavaScript بدون إطار عمل، عربية بالكامل ومصممة للجوال أولًا.
- **الخادم:** Netlify Functions (Node.js)، والتخزين Netlify Blobs.
- **محرك فحص الدواء:** قواعد مكتوبة بأيدينا من مصادر منشورة (MGFA وCPIC والنشرات الرسمية لـ FDA)، ولكل قاعدة مصدرها.
- **الباركود:** BarcodeDetector في المتصفح، وZXing كبديل.
- **الإشعارات:** Web Push.
- **الاختبارات:** 28 اختبارًا آليًا (`npm test`).

التشغيل المحلي والنشر وهيكل المشروع بالتفصيل في **[README_AR.md](README_AR.md)**.

```
npm install
npm run dev     # http://localhost:8888
npm test
```

## تنبيه

هذا نموذج أولي لهاكاثون **MEDATHON 2026**، وكل المرضى فيه شخصيات وهمية. قائمة الأدوية مسودة (v2) تنتظر المراجعة السريرية النهائية. المنصة تساعد الطبيب ولا تغني عن قراره، وليست مصرّحًا بها للاستخدام على مرضى حقيقيين بعد.

**AMAN** carries a patient's doctor-approved "medicines to avoid" list on an NFC bracelet. Any phone that taps it opens an emergency card and can check a medicine by name or by scanning the pack barcode. The treating doctor is alerted automatically on every "avoid" result. Built for MEDATHON 2026. All patient data is fictional.
